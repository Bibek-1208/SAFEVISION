# SafeVision AI — Dataset Preparation & Training Guide

> **"See the Risk. Prevent the Incident. Protect the Workforce."**

SafeVision AI utilizes a high-precision computer vision pipeline engineered specifically for industrial workplace safety, automated compliance auditing (OSHA 29 CFR 1910, DGFASLI), and early hazard detection.

---

## 1. Class Taxonomy & Annotation Guidelines

All annotations must adhere to strict bounding-box format `[class_id, x_center, y_center, width, height]` normalized from `0.0` to `1.0`.

| Class ID | Class Name | Description & Bounding Box Extent |
| :--- | :--- | :--- |
| `0` | `helmet` | Hardhat / safety helmet worn properly on head. Bounding box encompasses only the headwear. |
| `1` | `no_helmet` | Worker head detected without certified hardhat or head protection. |
| `2` | `safety_vest` | High-visibility reflective vest or neon safety apparel covering the torso. |
| `3` | `no_safety_vest` | Worker torso detected without high-visibility safety clothing in designated mandatory zones. |
| `4` | `gloves` | Protective industrial gloves on hands (cut-resistant, chemical, or thermal). |
| `5` | `no_gloves` | Bare hands in proximity to rotating machinery, pinch points, or chemical handling areas. |
| `6` | `safety_shoes` | Steel-toe or puncture-resistant safety boots covering the feet. |
| `7` | `no_safety_shoes` | Non-compliant footwear (sneakers, sandals, canvas shoes) detected on active plant floor. |
| `8` | `fire` | Open flames, combustion flare, or furnace blowouts. Bounding box covers flame core and glow. |
| `9` | `smoke` | Visible smoke plumes, aerosol release, or dense chemical vapors. |
| `10` | `worker_fall` | Worker horizontal or collapsed on the floor with duration exceeding 2.0 seconds. |

---

## 2. Privacy & Ethical Standards (Strict No-Biometrics Rule)

SafeVision AI enforces strict enterprise privacy standards:
1. **Zero Facial Recognition**: Facial features are never extracted, classified, or stored in facial databases.
2. **Ephemeral Tracking Identifiers**: Workers are assigned session-scoped tracking IDs (e.g. `WORKER-0012`, `WORKER-0045`) generated via ByteTrack / SORT tracking algorithms based on spatial coordinates, not facial geometry.
3. **GDPR / Labor Compliance**: Video frames stored for audit evidence capture bounding boxes and contextual environment without biometric indexing.

## 3. Dataset Directory Structure

The training pipeline expects the standard YOLO dataset layout generated by `ai/scripts/prepare_dataset.py`:

```
ai/datasets/industrial_ppe/
├── data.yaml
├── images/
│   ├── train/     (80% of dataset)
│   ├── val/       (15% of dataset)
│   └── test/      (5% of dataset)
└── labels/
    ├── train/
    ├── val/
    └── test/
```

### Dataset Ingestion Command
To prepare and split raw labeled data:
```bash
python scripts/prepare_dataset.py --source-images datasets/raw/images --source-labels datasets/raw/labels --output datasets/industrial_ppe
```

## 4. Training the Neural Model

Ensure the `ultralytics` package is installed in your virtual environment:
```bash
pip install ultralytics
```

Run training with industrial parameters:
```bash
python scripts/train.py --data configs/industrial_ppe.yaml --epochs 50 --batch 16 --imgsz 640 --model yolov8n.pt --output models
```

Trained weights will automatically be saved to `ai/models/industrial_yolov8.pt`. When the service restarts, SafeVision AI will automatically promote the engine status from `baseline_cv` to `configured`.

---

## 5. Model Evaluation & Target Quality Metrics

Run validation:
```bash
python scripts/evaluate.py --model models/industrial_yolov8.pt --data configs/industrial_ppe.yaml
```

### Target Quality Gates for Production Deployment:
- **mAP@50**: $\ge 0.88$ across all PPE classes
- **Precision (Fire/Smoke)**: $\ge 0.94$ (low false-positive emergency triggering)
- **Inference Latency**: $\le 35\text{ ms}$ per frame on 1080p stream
- **Temporal Verification Window**: $\ge 3.0\text{ seconds}$ persistence threshold to eliminate brief occlusion artifacts.

---

## 6. Edge Deployment Export (ONNX / TensorRT)

For deployment on NVIDIA Jetson Orin or edge industrial PCs:
```bash
# Export to ONNX
python scripts/export.py --model models/industrial_yolov8.pt --format onnx --imgsz 640

# Export to TensorRT Engine (for GPU appliances)
python scripts/export.py --model models/industrial_yolov8.pt --format engine --imgsz 640
```
